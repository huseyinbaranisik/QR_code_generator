## 🇬🇧 English

### 🚀 Project Overview
**Modern QR Generator** is a high-performance desktop application built with **Python**. It combines a minimalist dark-mode look with powerful image processing for a seamless user experience.

### 🌟 Key Features
* 🎨 **Premium UI:** Modern dark interface designed with **CustomTkinter**.
* 🔍 **Real-time preview:** QR codes are generated and shown instantly.
* 🌫️ **Visual effects:** Dynamic blur animation on hover for a polished feel.
* 💾 **Direct export:** One-click save in high-resolution **PNG** format.
* 📦 **Standalone:** Fully working `.exe` build with no external dependencies.

### 🛠️ Tech Stack

| Component | Technology | Role |
| :--- | :--- | :--- |
| **Backend** | Python 3.x | Logic & engine |
| **Frontend** | CustomTkinter | Modern UI/UX design |
| **Image core** | Pillow (PIL) | Processing & effects |
| **Generator** | QRCode | QR matrix encoding |

### 💻 Running
```bash
pip install customtkinter pillow qrcode
python Qr_code/code/main.py
```
